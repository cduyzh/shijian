# 食间 SHI JIAN

**正常吃饭，好好搭配。**

食间是一款面向川渝家庭的私人饮食规划 Web 应用，为两位有厨房经验的上班族安排 3–7 天的午餐、晚餐和每日水果。保留米饭、粥和熟悉的家常川菜，把注意力放在食材搭配、餐盘比例、烹饪方式与备菜安排上。

它希望解决三个日常问题：**吃什么、为什么这样搭配、接下来需要准备什么。**

## 产品体验

- **还没有计划时**，首页引导选择开始日期与规划天数，从家常菜库搭配第一份菜单。
- **已有计划时**，首页按天展示午餐、晚餐和水果，可查看菜谱、替换菜品，并继续安排下一个周期。
- **搭配有依据**，用通俗文字解释蛋白质来源、主食与杂粮、蔬菜种类和水果的角色，不将任何一道菜描述为“直接燃脂”。
- **食材叫法清楚**，按川渝常见品种建立独立条目，例如当前茄子明确为紫皮长茄，不将圆茄、线茄或白茄混入同一条目。
- **采购省心**，按食材类别归并菜单所需食材，可勾选已准备或标记家里已有。主界面以种类和用途为主，参考总预算默认折叠，可记录实际采购合计，不把克重、单价做成菜单阅读负担。
- **可爱且真实**，柔和配色、轻盈动效与写实食材插画结合；生成图片用于视觉说明，并非菜品实拍。
- **计划保存在本机**，通过浏览器 `localStorage` 保留当前、未来及历史周期，支持删除计划与 JSON 备份导入、导出。

## 内容与数据边界

食间估算的范围是**午餐、晚餐与水果**，不代表完整的一日摄入，也不提供个人医疗营养处方。营养与价格均为参考值，具体口径、来源和更新时间见[营养与数据来源](docs/NUTRITION-SOURCES.md)。

菜谱围绕常见家常食材整理，强调多样搭配、适量用油和可持续的正常饮食。烹饪方式、原料品种、可食部和实际用量变化，都会影响最终营养与成本。
