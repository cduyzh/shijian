# 食间 SHI JIAN

**正常吃饭，好好搭配。**

食间是一款面向川渝家庭的私人饮食规划 Web 应用，为两位有厨房经验的上班族安排 3–7 天的家常饮食。默认规划午餐、晚餐和每日水果，也可选择只安排晚餐与水果。保留米饭、粥和熟悉的家常川菜，把注意力放在食材搭配、餐盘比例、烹饪方式与备菜安排上。

它希望解决三个日常问题：**吃什么、为什么这样搭配、接下来需要准备什么。**

## 产品体验

- **自己决定每一餐**，先选开始日期与规划天数，默认从空餐盘逐餐挑选蛋白质菜、蔬菜与主食。也可以先获得正餐推荐，再自行调整；推荐不替用户选择水果。
- **水果主动选择**，每天的水果初始为空，须亲自选择后才能保存完整菜单。需要连吃几天同一种水果时，可明确勾选“这几天都选同一种水果”。
- **未完成也能继续**，搭配中的草稿保存在本机，返回首页或刷新后可接着选；完整保存前不会覆盖已有周期。
- **餐次由你决定**，可在设置中保存新菜单的默认餐次，也可为单个周期选择“午餐＋晚餐”或“只安排晚餐”。已保存计划保留自己的餐次，采购与营养按该周期计算。
- **已有计划时**，首页按天展示该周期选择的餐次和水果，可查看菜谱、替换菜品，并继续安排下一个周期。
- **搭配有依据**，用通俗文字解释蛋白质来源、主食与杂粮、蔬菜种类和水果的角色，不将任何一道菜描述为“直接燃脂”。
- **食材叫法清楚**，按川渝常见品种建立独立条目，例如当前茄子明确为紫皮长茄，不将圆茄、线茄或白茄混入同一条目。
- **采购省心**，按食材类别归并菜单所需食材，可勾选已准备或标记家里已有。主界面以种类和用途为主，参考总预算默认折叠，可记录实际采购合计，不把克重、单价做成菜单阅读负担。
- **成品看得见**，单菜卡片展示生成的熟菜图，整餐使用真实陶瓷餐盘照片与熟菜透明图进行 2D 摆盘，帮助理解餐盘搭配。点菜品查看做法，点食材查看品种、作用与储存；详情可切换成品效果与食材搭配，并返回上一级。生成图与 2D 摆盘均为示意。
- **图像统一自然轮廓**，食材使用透明原图与等比居中展示，统一视觉占比，按方形图卡浏览。页面使用温暖的奶油白与鼠尾草绿，配合轻量卡片反馈、面板过渡与选菜反馈；支持减少动态效果。
- **双人份量说清楚**，在展开的营养详情中查看原料克数、每人均分参考与双人合计；日常选菜和采购主界面仍以搭配与食材种类为主。
- **计划保存在本机**，通过浏览器 `localStorage` 保留当前、未来及历史周期，支持删除计划与 JSON 备份导入、导出。

## 内容与数据边界

食间按每份计划的餐次估算**午餐＋晚餐与水果**，或**晚餐与水果**，不代表完整的一日摄入，也不提供个人医疗营养处方。双人配方与单人均分分别列出，原料量使用可食部生重，米与干木耳按煮前干品重量。营养与价格均为参考值，具体口径、来源和更新时间见[营养与数据来源](docs/NUTRITION-SOURCES.md)。

菜谱围绕常见家常食材整理，强调多样搭配、适量用油和可持续的正常饮食。烹饪方式、原料品种、可食部和实际用量变化，都会影响最终营养与成本。

## 私人仓库与数据边界

此仓库已改为私人，保存完整静态应用源码、实际运行图片、第三方许可证与说明文档。持有仓库访问权限的维护者可以按本地开发说明启动项目。源码与生成资产未授予开源许可。

Git 不保存用户菜单、浏览器存储或备份导出；部署凭据、托管身份配置、验收导出及历史生成原图均被排除。静态网页一旦由浏览器加载，有权访问应用的人仍可查看 HTML、CSS、JavaScript 与图片。私人 GitHub 仓库与网页访问权限分别管理。

## 访问应用

[打开食间私人应用](https://shijian-kitchen.cduyzh.chatgpt.site)。入口使用 ChatGPT 登录，当前保持拥有者私人访问。每个浏览器各自保存菜单，迁移时请使用 JSON 备份。

当前本地内容库包括 82 种具名食材（含 18 种水果）、65 道家常菜与 6 篇科学饮食科普。营养及价格数值仍为明确标注的估算，不能用作精确营养计量或实际报价。本文记录当前源码实现。2026-10-14 更新恢复照片质感的 2D 餐盘，追加 12 种食材与 16 道菜，并提升 8 道常用菜的成品图片细节。本轮更新提交到私人仓库，未部署到线上。
