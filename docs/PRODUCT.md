# 食间产品说明

## 为谁设计

食间面向川渝地区的双人家庭，默认使用者已有两年以上厨房经验，能够判断实际采购数量、烹饪用量和菜市场价格。产品帮助安排组合和节奏，而不是要求每天称重记账。

规划覆盖连续 3–7 天的午餐、晚餐及水果。早餐、零食、饮料和临时加餐不在当前菜单范围内，因此页面中的营养说明不能被当成全天摄入评估。

## 首页的两种状态

**未安排菜单：** 用一句清楚的引导说明用途，展示开始日期、周期长度和菜谱灵感。让用户先完成一份可以修改的菜单，再逐步了解食材和科学依据。

**已安排菜单：** 展示当前周期与所选日期，将午餐、晚餐和水果放在同一日视图中。换一道菜时保留其他选择，相关搭配解释与采购汇总随菜单更新。未来周期和历史周期有明确入口，可在“我的菜单”中查看、调整或删除指定计划。新计划不能与已有周期重叠，避免只保存最后一份菜单。

## 菜单搭配

每餐主要考虑主食、蛋白质来源和蔬菜之间的组合。比例表达采用餐盘提示与食材角色说明，不将视觉比例换算为个体化处方，也不因为某道菜加入鸡蛋或肉就忽略其他菜中的同类原料。

菜谱库以川渝家庭熟悉的做法为主，包括青椒肉丝、少油宫保鸡丁、番茄炒蛋、莴笋木耳炒肉、蒜苗肉丝、冬瓜瘦肉汤、豆腐蒸蛋和家常蔬菜等。主食保留米饭，并提供燕麦米饭、黑米杂粮饭与粥类选择。不同组合可以轮换，避免每次规划都只出现同一套“减脂餐”。

菜谱详情说明食材角色、操作顺序、制作时间、搭配建议和储存方式。营养说明围绕均衡、多样与日常可行性展开，不承诺治疗疾病或特定减重结果。

## 食材分类与叫法

食材按主食、蛋白质、蔬菜、水果和调味品分类。名称优先采用川渝常见表达，另列常见别名与选择要点。

同一大类中的品种不自动视为完全等价：当前收录的茄子为紫皮长茄，青椒为二荆条青椒，豆腐区分卤水老豆腐与石膏嫩豆腐。圆茄、线茄、白茄、圆灯笼甜椒及其他凝固方式的豆腐，不能直接混入现有条目。替换食材时关注口感、烹饪时间和菜品用途。

图片辅助辨认真实外形、颜色和质地。可爱感来自构图、圆润视觉和少量表情装饰，不改变食材本身的品种特征。AI 生成图不能作为品种鉴定、食材新鲜度或实际成品效果的证据。

## 采购与成本

采购清单按食材类别合并，重点展示本周期会用到哪些食材及其用途。重复出现的食材归并，可勾选“已准备”或标记“家里已有”，也可复制清单带去买菜。

主菜单和日常搭配页面不展示克重、单价或逐项费用。“买菜清单”的参考预算摘要默认折叠，展开后显示待买食材的双人参考合计；标记“家里已有”的食材不计入参考合计。使用者可记录本次实际总花费，清空记录后恢复参考估算。参考价格为静态演示估算，不是实时市场报价；实际采购数量与最终花费仍由使用者掌握。

## 视觉与交互

整体采用轻盈、温暖的配色与有层次的卡片，让可爱的食材形象保持真实质感。交互参考 Apple 产品的清晰反馈、留白和细腻过渡，在手机上也能完成选日期、换菜和查看详情。

动效用于表达日期切换、菜单更新与卡片展开，不依赖动画传递关键信息。系统开启减少动态效果时，保留相同功能并缩短或取消动画。

## 当前交付方式

应用支持本地静态网页预览，菜单由浏览器本地保存；可导出 JSON 备份并在另一浏览器手动导入，导入需要确认替换现有记录。公开 GitHub 仓库只记录产品、数据与图片生成说明，应用核心文件和图片不上传。私人访问是产品目标，真正限制访问需要部署时另外配置访问控制。本文不表示公网部署已经完成。


## 补充交互

每餐可另加一道家常汤，汤羹作为附加搭配，不替代固定的蛋白质菜、蔬菜和主食。手机底栏提供六个主入口，顶部保存状态可打开本地数据设置。营养估算默认折叠，注明只涵盖单人的午晚餐与水果。
