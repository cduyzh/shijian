## 全部 37 道菜的熟制外观规范

共用要求：真实熟食、自然食材形状、温暖柔和的摄影质感、轻微水润光泽。炒菜不能出现大片油池、油炸厚壳或尚未变色的生肉。鸡蛋必须凝固，鸡肉必须是熟肉。可爱的质感来自圆润构图、温柔光线与器皿，不给食物画人脸。

## 少油家常改良的边界

1. 外观可有蒸汁或轻润光泽，但不画大面积油池、油炸壳和“越亮越好”的过度抛光食物。
2. 图像中的食材必须能在该菜当前配方中找到。网络参考含有的干辣椒、蚝油、淀粉、糖、芝麻、肉末、枸杞等，不因常见就自动画进食间的菜。
3. 二荆条、紫皮长茄、青蒜苗、青皮莴笋、嫩豆腐与老豆腐分别对应自己的形态。不能为了让图片更好看而换品种或把生鲜图贴在盘上冒充熟菜。
4. 宫保鸡丁明确属于无额外糖、少油的家常改良版；豆瓣烧豆腐未经油炸。图片不得反向改变这两个配方承诺。
5. 没有真实做菜拍摄或逐项烹调核验，图片就只称“AI 成品效果示意”，不称实际成品、精准比例或真实菜谱照片。
6. 37 道菜均有主菜、蔬菜、汤或主食的明确类别；汤图不能替代主蛋白的配餐含义，粥图不能暗示一碗就满足一餐或全天需求。

## 当前图像交互

`picture()` 输出展示用 `span`；操作由外层语义按钮提供。食材百科卡片、菜谱详情食材行、菜单中的食材标签与采购清单图片均可打开对应食材介绍，避免将展示组件全局变成按钮后产生嵌套控件。

- 每日菜单：成品菜图包 `button data-action="recipe" data-id="菜谱 ID"`，打开该菜做法。
- 今日水果：水果图包 `button data-action="ingredient" data-id="食材 ID"`，打开品种、挑选与储存信息。
- 买菜清单：食材图片包对应 `ingredient` 按钮，点击图片和名称具有一致含义。
- 餐盘内的主菜、蔬菜与主食：每个菜区是独立 `recipe` 按钮，打开对应菜谱。

菜谱详情提供“成品效果”和“食材搭配”切换；从选菜面板查看菜谱、再查看食材，可以按返回按钮回到上一级继续选择。装饰图片不承担选择功能。本文记录已写入的交互实现；实际视觉和交互验收由主 agent 统一完成。
